# Settings posture

The Settings page is a read-only summary of effective Codex Monitor behavior.
It reports loopback binding, telemetry state and encodings, prompt retention,
optional source analysis, Git-root discovery, scan interval, and the normalized
database schema version.

The page does not expose credentials, configuration-file contents, Codex paths,
or cache paths. It cannot modify Codex Monitor or Codex configuration.
